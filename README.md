# AI Companion Starter

A minimal Next.js starter for a private AI companion.

## Run locally / in Codespaces

1. Install dependencies:
   npm install

2. Copy `.env.example` to `.env.local`.

3. Put your API key in `.env.local`.

4. Start:
   npm run dev

Then open the local URL shown by Next.js.

## Important

Never commit `.env.local` or an API key to GitHub.
